# Stage 387 — ARM: отдельный макет счётчика патронов

Создан необязательный, доступный только через прямой вызов C++
`draw_battle_arm_status`, интерфейс магазина для экспериментальной
команды ARM.

## Отображение

Панель занимает строго ограниченную область экрана 1280×720:
`(944, 622, 286, 84)`. На ней показываются надпись ARM AMMO,
количество патронов и полоска наполнения, а при пустом магазине —
сообщение ARM EMPTY. Шрифт, цвета, пиксельные функции заимствуются
из уже существующего боя; никаких спрайтов Wild Arms PS1 нет.

## Проверки

Пять сценариев нового C++ тестового набора:

- Полный магазин и побитовое сохранение обычного кадра вне панели.
- После выстрела — ровно 2/3 полоски; после окончания боезапаса —
  пустая полоска, без старых пикселей в правой части.
- Неверный размер/шаг кадра, испорченный бой или магазин отбрасываются
  **до любой записи в буфер**.
- Реальное изменение ARM-боеприпасов влияет на экран, но прямой
  вызов UI не изменяет ни патроны, ни HP, ни результат боя.
- Максимальное допустимое значение магазина (255/255) не вызывает
  арифметического переполнения или выхода за пределы буфера.

**Граница:** этот модуль НЕ подключён к игровому циклу Nintendo
Switch и не меняет стандартную графику, клавиши A/Y/B, результаты
прежних NeXium-проверок или 52-байтный файл WABJ. Это
исследовательская подготовка интерфейса ARM с синтетическим балансом.

Дальнейшее включение в Native NRO должно выполняться только отдельным
этапом и с настоящими проверками кадров в NeXium, включая сравнение
с эталоном при отключённом ARM.
